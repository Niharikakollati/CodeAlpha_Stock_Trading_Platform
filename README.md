Stock Trading Platform is a Java-based application designed to simulate real-world stock market trading operations in a simplified environment. The platform allows users to buy and sell stocks, manage their investment portfolio, track account balances, and monitor stock transactions through an interactive console-based interface.

The project demonstrates the practical implementation of Object-Oriented Programming (OOP) concepts, data structures, and financial transaction management using Java. Users can view available stocks, perform trading operations, check portfolio holdings, and manage virtual investments based on predefined stock prices.

This application provides a beginner-friendly introduction to stock market concepts while helping users understand portfolio management, trading strategies, and financial decision-making. It also serves as a practical learning project for implementing business logic, transaction processing, and user interaction in software development.

Key Features:
• View available stocks and their prices
• Buy stocks using available balance
• Sell owned stocks and update portfolio
• Portfolio management and tracking
• Account balance monitoring
• Interactive menu-driven console interface
• Transaction handling and validation

Technologies Used:
• Java
• Object-Oriented Programming (OOP)
• Collections Framework (HashMap)
• Visual Studio Code
• Git & GitHub

This project was developed as part of the CodeAlpha Java Programming Internship to strengthen programming skills, understand financial application development, and gain hands-on experience with software design principles and version control systems.
